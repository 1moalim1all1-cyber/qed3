# Auto Parts Pro — نسخة مطورة للنشر

متجر قطع غيار عربي متجاوب، مع تسجيل Firebase وجملة للتجار المعتمدين وطلبات مراجعة ولوحة إدارة مقيدة بصلاحيات المدير.

**ابدأ من [SETUP.md](SETUP.md)**: تعليمات نشر Firebase، إنشاء المدير، اعتماد التجار، وتحذيرات الإطلاق.

> ربط Firebase لازم قبل إرسال الطلبات. السعر بالموقع تقديري والطلب لا يصبح فاتورة مؤكدة بشكل تلقائي. لا توجد بوابة دفع أو شحن أو واتساب API متصل بعد.
