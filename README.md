# Qed3 Auto Parts

مستودع مشروع قطع غيار السيارات Qed3.

## الحالة
النسخة التأسيسية قيد التجهيز **وليست جاهزة لاستقبال مدفوعات أو مبيعات حقيقية** قبل اختبار تسجيل العملاء، قواعد Firestore، واعتماد أسعار الطلبات عبر خادم آمن.

## الاستضافة
- GitHub Pages: ملفات واجهة الموقع الثابتة.
- Firebase project: `qed3-2a2d8` للبيانات والمصادقة.
- يجب عدم نشر Service Account أو مفاتيح خاصة هنا.

## رفع ملفات الواجهة
افتح المستودع > Add file > Upload files، واسحب محتويات مجلد المشروع المفكوكة (وليس ملف ZIP) مع الاحتفاظ بمجلد `assets/`. ثم اضبط Settings > Pages > Deploy from a branch > main / root.

## تنبيه مهم
إعداد `firebaseConfig` الخاص بالويب ليس بديلًا عن قواعد الأمان. قواعد Firestore يجب نشرها واختبارها بصورة منفصلة، ونظام الدخول برقم الهاتف وكلمة المرور دون SMS ما زال يتطلب Backend آمنًا.
